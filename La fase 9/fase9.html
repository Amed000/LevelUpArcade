Fase 09

Fase 9 - Memoria Web del Proyecto

Esta fase explica cómo se preparó la web que presenta el proyecto LevelUp Arcade.

Objetivo

Objetivo de la fase

Crear una memoria web estática, moderna y fácil de navegar que reúna las fases 1 a 10 del proyecto LevelUp Arcade, integrando el contenido trabajado y sus capturas.

Tecnologias

Tecnologías usadas para crear esta web

HTML5

Estructura semántica para portada, fases, galerías y presentación.

CSS3

Diseño dark gaming, glassmorphism, glow neon, responsive y cursor personalizado.

JavaScript

Menú móvil, progreso de lectura, lightbox, scroll reveal y partículas animadas.

Python

Preparación del contenido y organización de las capturas de la memoria.

Estructura de archivos

Diseno

Decisiones de diseno

  • Se eligio una estetica dark gaming con fondo negro, cian electrico y morado neon.
  • Orbitron se usa en titulares para reforzar el caracter arcade y tecnologico.
  • Las tarjetas tienen efecto glassmorphism, borde luminoso y elevacion al pasar el cursor.
  • Las galerias abren capturas en lightbox para revisar diagramas y pantallas sin salir de la pagina.
  • La web no necesita servidor: funciona abriendo directamente los HTML con rutas relativas.

## 📖 Descripción

Esta web constituye la **memoria técnica y visual** del proyecto LevelUp Arcade. Ha sido desarrollada íntegramente con tecnologías web estándar (sin frameworks pesados) y recoge todo el trabajo realizado a lo largo de las 10 fases del proyecto: análisis, diseño, infraestructura, codificación, IA, pruebas, seguridad, despliegue e interfaz gráfica.

El objetivo es presentar el proyecto de forma **clara, estructurada y profesional**, con contenido visual que facilite su comprensión.

## 🎨 Diseño visual

La web sigue una estética **dark gaming / tech futurista** coherente con la identidad de LevelUp Arcade:

- 🎨 **Paleta:** fondo negro `#0a0a0a`, acento neón morado `#a855f7` y cian `#00f5ff`
- 🔤 **Tipografía:** `Orbitron` para títulos · `Rajdhani` / `Inter` para cuerpo
- ✨ **Efectos:** glow neón, glassmorphism, gradientes, partículas animadas en el hero
- 📱 **Responsive:** adaptada a móvil, tablet y escritorio
- 🖱️ **Animaciones:** aparición al scroll, hover en cards, navbar dinámica

## 🛠️ Tecnologías y librerías

| Librería | Uso |
|---|---|
| [AOS.js](https://michalsnik.github.io/aos/) | Animaciones de aparición al hacer scroll |
| [particles.js / tsParticles](https://particles.js.org/) | Fondo animado con partículas en el hero |
| [GLightbox](https://biati-digital.github.io/glightbox/) | Lightbox para ampliar imágenes y capturas |
| [Google Fonts](https://fonts.google.com/) | Tipografías Orbitron e Inter |
| HTML5 + CSS3 + JS vanilla | Base de toda la web |

> No se requiere servidor ni build. Todo funciona abriendo los archivos directamente en el navegador.

## ▶️ Cómo visualizarla

**Abrir directamente en el navegador:**

```bash
# Clona el repositorio
git clone https://github.com/tu-usuario/levelup-arcade.git

# Navega a la carpeta de la memoria
cd levelup-arcade/memoria-web

# Abre el archivo de inicio
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

## ⚡ Funcionalidades interactivas

- **Navbar fija** con efecto blur al hacer scroll y menú hamburguesa en móvil
- **Partículas animadas** en el hero de la página de inicio
- **Cards con efecto hover** y glow neón para cada fase
- **Animaciones al scroll** en todas las secciones (AOS.js)
- **Barra de progreso de lectura** en la parte superior de cada página de fase
- **Lightbox** para ampliar capturas de pantalla y diagramas al hacer clic
- **Scroll suave** entre secciones
- **Navegación entre fases** con botones "← Anterior" y "Siguiente →"

Fase 07

Fase 7 - Seguridad

Login, roles, permisos y almacenamiento seguro de contrasenas.

Objetivo

Objetivo de la fase

Proteger el acceso a la aplicacion y limitar las acciones segun el rol del usuario.

Desarrollo

Desarrollo del trabajo realizado

FASE 7) SEGURIDAD
• Crear un sistema de login de usuarios, en el que habrá dos roles bien
diferenciados:
1. Administrador: podrá realizar todas las operaciones del sistema
(CRUD completo y gestión de datos).
2. Empleado: solo podrá realizar consultas de datos (lectura), sin
permisos de modificación:

• Las contraseñas de los usuarios deberán almacenarse de forma segura. No
podrán guardarse en texto plano, sino mediante técnicas de cifrado o hash.
Decisiones

Decisiones técnicas tomadas

  • Se diferencian permisos completos para Administrador y permisos de lectura para Empleado.
  • Las contrasenas se almacenan con hash, no en texto plano.
  • La tabla de usuarios guarda nombre, password_hash y rol.
  • La interfaz debe adaptar acciones disponibles segun permisos.
Resultados

Resultados obtenidos

  • Sistema de login incorporado.
  • Control de roles ADMIN y EMPLEADO documentado.
  • Estructura SQL preparada para hashes de contrasena.
  • Codigo Java de validacion y seguridad implementado.

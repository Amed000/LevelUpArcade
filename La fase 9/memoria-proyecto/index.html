Descripcion general

Resumen general del proyecto

LevelUp Arcade centraliza la gestion de productos, clientes, proveedores y pedidos para una tienda de videojuegos y merchandising. La solucion sustituye hojas de calculo por una aplicacion Java conectada a MySQL/MariaDB, con roles de usuario y funciones de IA para acelerar la gestion de productos.

Objetivos

Objetivos principales

  • Digitalizar la gestion de inventario, clientes y proveedores.
  • Reducir errores humanos y duplicidad de datos.
  • Centralizar la informacion en una base de datos relacional.
  • Automatizar tareas con IA mediante OpenRouter.

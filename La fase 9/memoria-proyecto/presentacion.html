Proyecto

Resumen ejecutivo

LevelUp Arcade es una aplicación de escritorio desarrollada en Java para gestionar una tienda de videojuegos y merchandising. El proyecto recoge todo el proceso: análisis, diseño, infraestructura, codificación, inteligencia artificial, pruebas, seguridad, despliegue e interfaz gráfica.

Logros

Logros conseguidos

  • Modelo de datos normalizado y conectado a MySQL/MariaDB.
  • Aplicación Java organizada con arquitectura MVC.
  • Roles de usuario, login y contraseñas protegidas con hash.
  • Integración con OpenRouter para funciones de IA.
  • Backups automáticos, pruebas JUnit y despliegue como archivo JAR.
  • Interfaz gráfica Swing para una experiencia más clara y profesional.

Conclusión

Conclusiones

El resultado final es una aplicación completa para gestionar la tienda de forma más ordenada, con datos centralizados, control de usuarios, copias de seguridad y una interfaz gráfica que facilita el trabajo diario.
